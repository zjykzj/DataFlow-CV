## 一、概述
YOLO（You Only Look Once）是一种流行的目标检测算法，其标签格式用于存储标注信息。每个图像对应一个 `.txt` 文本文件，文件中每行表示一个目标实例。

## 二、文件构成和属性
YOLO 标签文件是纯文本文件，每行格式为：
```
<class_index> <cx> <cy> <w> <h> [<px1> <py1> <px2> <py2> ...]
```

- **class_index**：类别索引（整数），从 0 开始
- **cx, cy**：边界框中心点的归一化坐标（0-1）
- **w, h**：边界框宽度和高度的归一化值（0-1）
- **px, py**：（可选）实例分割的多边形点坐标，归一化值（0-1）

对于纯检测任务，每行有 5 个值；对于实例分割任务，多边形点序列追加在边界框之后。

## 三、标注类型

### 目标检测（边界框）
YOLO 主要设计用于目标检测，每个目标使用一个边界框表示。边界框格式为：
- `class_index`: 类别索引（整数）
- `cx`: 边界框中心点的归一化 x 坐标（0-1）
- `cy`: 边界框中心点的归一化 y 坐标（0-1）
- `w`: 边界框宽度的归一化值（0-1）
- `h`: 边界框高度的归一化值（0-1）

**边界框计算示例**：
- 图像尺寸：640×480 像素
- 目标边界框：像素坐标为左上角 (100, 80)，右下角 (300, 320)
- 计算归一化坐标：
  - 中心点：cx = (100 + 300)/2 / 640 = 0.3125，cy = (80 + 320)/2 / 480 = 0.4167
  - 宽度：w = (300 - 100) / 640 = 0.3125，高度：h = (320 - 80) / 480 = 0.5
- YOLO 格式行：`0 0.3125 0.4167 0.3125 0.5`

### 实例分割（多边形点列表）
YOLO 格式支持实例分割，通过在边界框后追加多边形点序列来描述目标轮廓。格式为：
- 前 5 个值：`class_index cx cy w h`（边界框）
- 后续值：`px1 py1 px2 py2 ...`（多边形顶点归一化坐标）

**多边形点列表特性**：
- 每个多边形由一系列 (x, y) 点组成
- 点坐标是归一化的（0-1）
- 多边形可以是任意形状，点数量可变
- 边界框通常从多边形点计算得出（最小外接矩形）

**实例分割示例**：
- 图像尺寸：640×480 像素
- 多边形顶点像素坐标：[(150, 100), (200, 80), (250, 120), (220, 150), (180, 140)]
- 归一化转换：每个点除对应图像尺寸
- YOLO 格式行：`0 0.3125 0.4167 0.3125 0.5 0.2344 0.2083 0.3125 0.1667 0.3906 0.2500 0.3438 0.3125 0.2813 0.2917`

## 四、坐标系统
YOLO 使用**归一化坐标系统**，所有坐标值范围在 0 到 1 之间：

### 坐标转换公式
- **像素坐标 → 归一化坐标**：
  - $x_{norm} = \frac{x_{pixel}}{image\_width}$
  - $y_{norm} = \frac{y_{pixel}}{image\_height}$
- **归一化坐标 → 像素坐标**：
  - $x_{pixel} = x_{norm} \times image\_width$
  - $y_{pixel} = y_{norm} \times image\_height$

### 边界框坐标转换
YOLO 边界框使用**中心点坐标**表示：
- **像素边界框**：$[x_{min}, y_{min}, x_{max}, y_{max}]$
- **转换为 YOLO 格式**：
  - $cx = \frac{x_{min} + x_{max}}{2 \times image\_width}$
  - $cy = \frac{y_{min} + y_{max}}{2 \times image\_height}$
  - $w = \frac{x_{max} - x_{min}}{image\_width}$
  - $h = \frac{y_{max} - y_{min}}{image\_height}$

### 示例：完整坐标转换
假设图像尺寸为 640×480 像素：

1. **像素坐标到归一化坐标**：
   - 像素点 (320, 240) → 归一化 (0.5, 0.5)
   - 计算：320/640 = 0.5，240/480 = 0.5

2. **边界框转换**：
   - 像素边界框：[100, 80, 300, 320]
   - 计算：
     - cx = (100 + 300) / (2 × 640) = 400 / 1280 = 0.3125
     - cy = (80 + 320) / (2 × 480) = 400 / 960 = 0.4167
     - w = (300 - 100) / 640 = 200 / 640 = 0.3125
     - h = (320 - 80) / 480 = 240 / 480 = 0.5
   - YOLO 格式：`0 0.3125 0.4167 0.3125 0.5`

3. **多边形点转换**：
   - 像素多边形点：[(150, 100), (200, 80), (250, 120)]
   - 归一化：
     - (150/640, 100/480) = (0.2344, 0.2083)
     - (200/640, 80/480) = (0.3125, 0.1667)
     - (250/640, 120/480) = (0.3906, 0.2500)

## 五、与其他格式的转换

### YOLO ↔ COCO 转换

#### 转换步骤
1. **读取 YOLO 标签**：解析每个 `.txt` 文件，获取边界框和多边形数据
2. **坐标转换**：将归一化坐标转换为绝对像素坐标（需要图像尺寸）
3. **类别映射**：将类别索引映射到 COCO 类别名称或 ID
4. **构建 COCO JSON**：创建 `images`、`annotations`、`categories` 结构
5. **处理分割**：将多边形点序列转换为 COCO 多边形格式或 RLE

#### 无损性分析
- **YOLO → COCO**：可以无损转换，因为归一化坐标可以精确转换为像素坐标
- **COCO → YOLO**：可以无损转换，但需注意 COCO 的多边形可能比 YOLO 支持的点数多，需要采样或简化

### YOLO ↔ LabelMe 转换

#### 转换步骤
1. **读取 YOLO 标签**：解析每个 `.txt` 文件
2. **坐标转换**：将归一化坐标转换为绝对像素坐标
3. **构建 LabelMe JSON**：创建 `shapes` 数组，每个形状包含 `label`、`points`、`shape_type`
4. **处理形状类型**：边界框对应 `rectangle`，多边形对应 `polygon`

#### 无损性分析
- **YOLO → LabelMe**：可以无损转换，多边形点序列可直接使用
- **LabelMe → YOLO**：可以无损转换，但 LabelMe 支持多种形状类型（矩形、圆形、多边形），需统一转换为多边形表示

## 六、文件示例

### 类别文件 (classes.txt)
```
person
bicycle
car
motorbike
```

### 标签文件 (image1.txt)
**目标检测示例**（两个目标）：
```
0 0.3125 0.4167 0.3125 0.5
2 0.6250 0.7500 0.1875 0.1667
```

**实例分割示例**（一个目标）：
```
0 0.3125 0.4167 0.3125 0.5 0.2344 0.2083 0.3125 0.1667 0.3906 0.2500 0.3438 0.3125 0.2813 0.2917
```

### 文件结构
```
dataset/
├── images/
│   ├── image1.jpg
│   └── image2.jpg
├── labels/
│   ├── image1.txt
│   └── image2.txt
└── classes.txt
```

**说明**：
- `image1.jpg` 的标签文件是 `image1.txt`（同名）
- 每个 `.txt` 文件行数等于图像中的目标数
- 类别索引对应 `classes.txt` 中的行号（从 0 开始）

## 七、注意事项
1. **类别文件**：YOLO 格式需要一个独立的类别文件（如 `classes.txt`）将索引映射到类别名称
2. **图像尺寸**：坐标归一化依赖于图像尺寸，转换时需要原始图像宽度和高度
3. **多边形点数**：YOLO 格式对多边形点数没有限制，但某些实现可能有最大点数约束
4. **坐标精度**：文本文件中的浮点数精度可能影响转换的精确性
